1. OS의 커널
    => OS의 핵심 서비스를 담당하는 부분을 커널이라고 합니다. (자원에 접근하거나 조작, 프로그램 RAM 적재..)
    => OS가 설치된 모든 기기에는 커널이 존재 / 커널은 사람의 심장이나 엔진 같은 역할을 합니다.
    => OS가 제공하나 커널에 포함되지 않는 서비스 -> 사용자 인터페이스


2. 이중 모드와 시스템 호출
    => OS는 사용자가 실행하는 응용 프로그램이 직접 하드웨어 자원에 접근하는 것을 방지하여 자원을 보호합니다.
    => OS는 응용 프로그램들이 자원에 접근하려고 할 떄 OS를 통해서만 접근하도록하여 자원을 보호합니다.
    => 응용 프로그램 요청 -> OS 커널 영역 코드 실행 -> 하드웨어 접근

    => 이중 모드란 CPU가 명령어를 사용하는 모드를 사용자 모드와 커널 모드로 구분하는 방식입니다.
    => 사용자 모드는 OS 서비스를 제공받을 수 없는 실행 모드입니다. -> 일반적으로 응용 프로그램은 사용자 모드로 실행됩니다.
    => 커널 모드는 OS 서비스를 제공받을 수 있는 실행 모드입니다. -> 커널 모드로 실행하면 자원에 접근하는 명령어를 비롯한 모든 명령어 실행 가능
    => 사용자 모드로 실행되는 프로그램이 자원에 접근하는 OS 서비스를 제공받으려면 OS에 요청을 보내 커널 모드로 전환되어야 합니다.
    => 이 떄 OS 서비스를 제공받기 위한 요청을 시스템 호출(System call)이라고 합니다.
    
    => CPU가 사용자 모드인지, 커널 모드인지 플래그 레지스터 속 슈퍼바이저 플래그를 보면 알 수 있습니다.

    => 시스템 호출은 소프트웨어적인 인터럽트입니다.
    => 인터럽트를 발생시키는 특정 명령어에 의해 발생하기도 하는데 이를 소프트웨어 인터럽트라고 합니다.
    => 응용 프로그램이 하드 디스크에 데이터 저장하려고 함
    => 응용 프로그램이 하드 디스크에 데이터를 저장하는 시스템 호출을 발생 -> 커널 모드로 전환 
            -> OS 내의 하드 디스크에 데이터 저장하는 코드 실행 -> 하드 디스크에 접근 -> 작업 완료 -> 사용자 모드 복귀 -> 응용 프로그램 실행


3. OS의 핵심 서비스
    3-1. 프로세스 관리
        => 메모리에 적재되어 실행중인 프로그램을 프로세스라고 합니다.
        => CPU는 한 번에 하나의 프로세스만 실행할 수 있습니다.
        => CPU는 프로세스를 실행 -> 전환 -> 실행 -> 전환.. 과정을 빠르게 반복합니다.
        => 프로세스는 상태, 사용하고자 하는 자원 다양 -> OS가 적절히 관리합니다.
    
    3-2. 자원 접근 및 할당
        => CPU, 메모리, 입출력장치를 제어합니다.
    
    3-3. 파일 시스템 관리
        => 파일 시스템은 OS가 지원하는 핵심 서비스입니다.
