1. 운영체제란
    => 실행할 프로그램에 필요한 자원을 할당하고, 프로그램이 올바르게 실행되도록 돕는 특별한 프로그램이 운영체제입니다.
    => 자원 (Resource) : CPU, 메모리, 보조기억장치, 입출력장치 등과 같은 컴퓨터 부품

    => OS도 프로그램이기에 메모리에 적재되어야 합니다.
    => OS는 특수한 프로그램이기에 컴퓨터가 부팅될 때 메모리 내 커널 영역에 적재되어 실행됩니다.
    => OS 부팅 : 컴퓨터 전원을 켠 뒤, CPU가 OS를 실행할 수 있는 상태까지 컴퓨터를 초기화하고 OS를 메모리에 적재하는 과정입니다.
    => 부팅 : 컴퓨터나 전자기기의 전원이 켜지거나 재시작된 후, 시스템이 정상적으로 동작할 수 있는 상태까지 필요한 초기화와 프로그램 실행을 수행하는 과정입니다.
    => 사용자가 이용하는 응용 프로그램이 적재되는 영역은 사용자 영역이라고 합니다.
    => OS는 커널 영역에 적재되어 사용자 영역에 적재된 프로그램에 자원을 할당하고 적절하게 실행되도록 돕습니다.
    => 응용 프로그램 : 사용자가 특정 목적을 위해 사용하는 일반적인 프로그램
    
    => 메모리 주소가 겹치지 않도록 적당한 공간에 프로그램 적재
    => 더 이상 실행되지 않는 프로그램 메모리에서 삭제
    => OS가 메모리 자원을 관리합니다.

    => 응용 프로그램이 실행되려면 CPU가 필요합니다.
    => 여러 프로그램이 적절하게 실행될 수 있도록 OS가 CPU 자원을 할당합니다.


2. 운영체제를 알아야 하는 이유
    => OS가 하드웨어를 조작하고 관리하는 기능들을 제공하기에 개발자가 하드웨어 조작 코드를 직접 작성할 필요가 없습니다.
    => OS는 프로그램이 하드웨어 상 어떻게 작동하는지 자세히 파악 -> OS도 프로그램 -> 이해할 수 있음 -> 문제 해결 능력 상승에 기여
