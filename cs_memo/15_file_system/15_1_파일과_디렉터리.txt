1. 파일과 디렉터리
    => 파일과 디렉터리는 OS 내부 파일 시스템이 관리하는 존재입니다.
    => 파일과 디렉터리는 보조기억장치에 있는 data -> 파일 시스템이 파일과 디렉터리로 관리합니다.


2. 파일
    2-1. 파일이란 하드 디스크나 SSD 같은 보조기억장치에 저장된 관련 정보의 집합입니다.
    2-2. 파일에는 이름, 파일을 실행하기 위한 정보, 파일 관련 부가 정보가 있습니다.
        => 부가 정보를 속성 또는 메타데이터라고 부릅니다.

    2-3. 파일 속성과 유형
        => 파일 시스템은 파일별로 파일_속성과_유형_확장자.png와 같은 속성을 유지하고 관리합니다.
        => 파일 유형이 다르면 실행 양상이 달라집니다. -> 텍스트 파일, 음악 파일, 실행 파일..
        => 파일 유형을 알리기 위해 확장자를 이용합니다. 확장자는 파일 종류가 무엇인지 OS에게 알려주는 힌트와 같습니다.
    
    2-4. 파일 연산을 위한 시스템 호출
        => 파일을 다루는 모든 작업은 OS에 의해 이뤄집니다.
        => OS는 파일 연산을 위한 시스템 호출을 제공합니다. (파일 생성, 파일 삭제, 파일 열기/닫기, 파일 읽기/쓰기)


3. 디렉터리 (Directory)
    3-1. 파일들을 효율적으로 관리하기 위해 디렉터리를 사용합니다.
        => Windows OS에서 디렉터리를 폴더라고 부릅니다.
    
    3-2. 과거 OS는 하나의 디렉터리만 존재했습니다.
        => 모든 파일이 하나의 디렉터리 아래에 존재 / 이와 같은 구조를 1단계 디렉터리라고 부릅니다.
    
    3-3. 1단계 디렉터리로는 많은 파일을 관리하기 어렵기에 여러 계층을 가진 트리 구조 디렉터리가 생겨났습니다.
        => 트리 구조 디렉터리는 최상위 디렉터리가 있고 그 아래에 여러 서브 디렉터리(자식 디렉터리)가 있을 수 있습니다.
        => 서브 디렉터리는 또 다른 서브 디렉터리를 가질 수 있습니다.
        => 최상위 디렉터리는 흔히 루트 디렉터리라고 부르고 슬래시(/)로 표현합니다.
        => Windows에서 최상위 디렉터리는 C:\라고 표현합니다.
    
    3-4. 절대 경로와 상대 경로
        1. 절대 경로
            => 모든 파일은 루트 디렉터리에서 자기 자신까지 이르는 고유한 경로를 의미합니다.
        2. 상대 경로
            => 현재 디렉터리부터 시작하는 경로입니다.  
    
    3-5. 디렉터리 연산을 위한 시스템 호출
        => OS는 디렉터리를 연산을 위한 시스템 호출을 제공합니다. (디렉터리 생성/삭제, 디렉터리 열기/닫기, 디렉터리 읽기)
    
    3-6. 디렉터리 엔트리
        => 많은 OS에서 디렉터리를 특별한 형태의 파일로 간주합니다. -> 디렉터리도 파일입니다.
        => 디렉터리 내부에는 해당 디렉터리에 담겨 있는 대상과 관련된 정보를 담고 있습니다.
        => 정보는 레이블(표) 형태로 구성되고 보조기억장치에 테이블의 형태의 정보로 저장됩니다.
        => 각각의 엔트리(행)에 담기는 정보는 파일 시스템 별로 다릅니다.
        => 다만, 디렉터리에 포함된 대상의 이름과 그 대상이 보조기억장치 내에 저장된 위치를 유추할 수 있는 정보는 공통적으로 존재합니다.
        => 파일 시스템에 따라 디렉터리 엔트리에 파일 속성을 명시하는 경우도 존재합니다.
