1. 교착 상태
    => 일어나지 않을 사건을 기다리며 진행이 멈춰 버리는 현상을 교착 상태라고 합니다.
    => 게임 프로세스는 자원 A를 점유 / 웹 브라우저 프로세스는 자원 B를 점유
        -> 이 떄 게임은 A를 점유한 채 웹 브라우저 자원 B가 필요하고, 웹 브라우저는 B를 점유한 채 게임의 자원 A가 필요
        -> 상대방이 가진 자원을 기다리기만 하다가 실행 한 번 못하는 상황 -> 교착상태


2. 자원 할당 그래프
    => 프로세스가 어떤 자원을 사용하고 있고, 프로세스가 어떤 자원을 기다리고 있는지 표현한 그래프입니다.
    => 그리는 방법
    2-1. 프로세스는 원으로 자원의 종류는 사각형으로 표현합니다.
    2-2. 사용할 수 있는 자원의 개수는 자원 사각형 내에 점으로 표현합니다.
        => CPU 하나는 사각형으로 표현, 사용가능한 CPU는 점으로 표현 (CPU - 코어)
    2-3. 프로세스가 자원을 할당받아 사용 중이라면 자원에서 프로세스를 향해 화살표를 표시합니다.
    2-4. 프로세스가 어떤 자원을 기다리고 있다면 프로세스에서 자원으로 화살표를 표시합니다.
    => 교착 상태가 일어난 자원 할당 그래프는 원의 형태를 띄고 있습니다.


3. 교착 상태 발생 조건
    => 교착 상태 발생 조건은 4가지가 존재합니다.
    => 4가지 조건을 모두 만족되면 교착 상태가 발생할 가능성이 생기고 하나라도 만족하지 않는다면 교착 상태가 발생하지 않습니다.
    3-1. 상호 배제
        => 한 프로세스가 사용하는 자원을 다른 프로세스가 사용할 수 없는 상태입니다.
    3-2. 점유와 대기
        => 자원을 할당받은 상태에서 다른 자원을 할당받기를 기다리는 상태입니다.
    3-3. 비선점
        => 어떤 프로세스도 다른 프로세스의 자원을 강제로 빼앗지 못하는 상태입니다.
    3-4. 원형 대기
        => 자원 할당 그래프에가 원의 형태로 그려지는 상태입니다.
