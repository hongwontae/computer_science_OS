1. C 코드를 컴파일러와 링커를 통해 실행 파일을 구성합니다.

2. 1의 과정에서 코드 영역, 데이터 영역, 스택 영역, 힙 영역에 정보가 구성됩니다.

3. OS는 실행 파일의 정보를 바탕으로 가상 주소 공간을 구성합니다.
    => 리눅스에서는 exeve()를 호출하면서 실행 파일을 분석합니다.
    => 가상 주소 공간은 0 ~ n까지 구성됩니다.

4. 3을 통해 나온 가상 주소 공간에 대한 정보는 OS가 관리합니다.
    3-1. mm_struct : 프로세스 가상 주소 공간 전반에 대한 정보
    3-2. vm_area_struct : 코드, 데이터, 힙, 스택 등의 가상 메모리 영역별 정보
    3-3. 페이지 테이블 : 가상 페이지와 메모리의 매핑 정보

5. MMU -> 페이지 테이블을 이용해 가상 주소를 물리 주소로 변환하는 CPU에 포함된 하드웨어 장치입니다.
