** OS가 프로세스의 정보를 갖추고 있고 OS가 그 정보를 MMU에게 전달합니다. **
** 보호 모드를 탑재한 CPU가 OS를 또 거치지 않고 MMU를 통해 보호 모드 실행 **


1. 프로세스가 죽는 대표적인 상황
    1-1. 프로그램 정상적으로 종료
        => c에서 main에서 return 0;

    1-2. 잘못된 메모리 접근
        => 유효하지 않은 주소에 값을 쓰려고 합니다.
        => OS 환경에 따라 에외를 발생시키고, OS가 프로그램을 종료할 수 있습니다.

    1-3. 프로그램 내부에서 오류 발생
        => 정수의 0 나눗셈 -> 예외로 인해 프로그램 종료


2. 프로세스 A가 실행하다가 죽었습니다.
    => OS가 프로세스 A가 실행하다가 죽으면 종료 요청이나 예외가 발생합니다. (소프트웨어 인터럽트 -> 예외)
    => 그러면 OS가 프로세스가 사용하는 프레임을 회수하고 다시 사용할 수 있는 공간이라고 알려야 합니다.
    => 이 떄 프로세스 A의 페이지 테이블을 확인하면서 회수하고 다시 사용할 수 있는 공간이라고 알립니다.
