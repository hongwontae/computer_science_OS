1. 프로그램의 논리 주소 공간은 RAM에 실제로 존재하는 공간이 아닙니다.
    1-1. 프로세스가 사용할 수 있다고 OS가 만들어 놓은 주소들의 범위입니다.
        => 그 범위 안에서 CPU가 특정 메모리 위치를 가리키기 위해 만든 하나의 주소가 논리 주소입니다.
    1-2. int x = 10;
        => 프로그램 입장에서는 x가 어떤 논리 주소에 있다고 생각합니다. (x -> 0x1234)
        => 0x1234 -> MMU -> 0xA234 (살재 주소)
    1-3. 각 프로세스마다 자기만의 논리 주소 공간이 존재합니다.
    1-4. MMU + 페이지 테이블을 통해 물리 주소로 연결합니다.
