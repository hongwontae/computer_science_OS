1. 연속 메모리 할당
    => 메모리 공간에 프로세스가 연속적으로 적재되는 방식을 의미합니다.


2. 스와핑
    => 메모리에 적재된 프로세스들 중에는 현재 실행되지 않거나 입출력 작업으로 대기 상태거나 오랫동안 사용되지 않은 프로세스들은
        보조기억장치 일부 영역으로 보내고 빈 공간 메모리에 다른 프로세스를 적재하여 실행하는 방식을 의미합니다.
    => 내보내진 프로세스들이 보조기억장치로 향하는데 이 영역을 스왑 영역이라고 합니다.
    => 메모리 내 프로세스 -> 스왑영역, 이를 스왑 아웃이라고 합니다.
    => 스왑영역 -> 메모리 내 프로세스, 이를 스왑 인이라고 합니다.
    => 스와핑을 사용하면 메모리 주소 공간의 크기가 실제 메모리 크기보다 큰 경우에도 프로세스들을 동시 실행할 수 있습니다.


3. 메모리 할당
    => 프로세스는 메모리의 빈 공간에 적재되어야하고, 메모리 내에 빈 공간이 여러 개 존재합니다.
    => 대표적으로 최초 적합, 최적 적합, 최악 적합 세 가지 방식이 존재합니다.
    
    3-1. 최초 적합
        => OS가 메모리 빈 공간을 순서대로 검색하다가 적재할 수 있는 공간을 발견하면 그 공간에 프로세스를 배치하는 방식입니다.
    
    3-2. 최적 적합
        => OS가 빈 공간을 모두 검색한 후, 프로세스가 적재될 수 있는 공간 중 가장 작은 공간에 프로세스를 배치하는 방식입니다.
    
    3-3. 최악 적합
        => OS가 빈 공간을 모두 검색한 후, 프로세스가 적재될 수 있는 공간 중 가장 큰 공간에 프로세스를 배치하는 방식입니다.


4. 외부 단편화
    => 프로세스를 할당하기 어려울 만큼 작은 메모리 공간들로 인해 메모리가 낭비되는 현상을 의미합니다.
    => 외부 단편화를 해결하는 방법 -> 메모리 압축
    => 흩어져 있는 빈 공간을 하나로 모으는 방식으로 메모리 내에 저장된 프로세스를 적당히 재배치시켜 
        여기저기 흩어져 있는 작은 빈 공간들을 하나의 큰 빈 공간으로 만드는 방법입니다.
    => 메모리 압축 동안 시스템은 일을 중지 / 메모리 내용을 옮기는 작업은 큰 오버헤드 / 최적의 메모리 압축 알고리즘 결정 어려움
    => 이러한 외부 단편화 해결 방법으로 페이징 기법이 나타났습니다.
