1. C/C++ 실행 파일
    1-1. 실행 파일은 기계어 뿐만 아니라 프로그램을 실행하기 위해 
            여러 정보가 정해진 형식에 따라 저장된 바이너리 파일입니다.
    
    1-2. C/C++ 파일 -> 실행 파일 과정
        => 전처리 -> 컴파일 -> 링킹 -> 실행 파일 생성
    

2. windows 실행 파일은 PE 형식을 사용합니다.
    2-1. PE(Portable Executable)는 실행 파일 내부에 어떤 정보가 어디에 저장되어 있는지 정의한 규칙입니다.

    2-2. 파일 형식이란?
        => 컴퓨터 입장에서 파일은 바이트들의 연속적인 데이터입니다.
        => 48 65 6C 6C 6F
        => ASCII로 해석하면 Hello입니다.
        => 중요한 것은 바이트 자체에는 이것이 문자열인지, 이미지인지, 실행 프로그램인지 전혀 있지 않습니다.
        => 파일 형식이란 바이트 데이터의 어떤 위치에 어떤 정보가 존재하고, 그 정보를 어떻게 해석해야 하는지를 정의한 규칙입니다.
    
    2-3. 확장자란?
        => 확장자는 파일 이름의 일부이며, 사람과 OS가 파일의 용도를 쉽게 구분하도록 도와주는 표시입니다.
    
    2-4. PE 구조는 크게 헤더, 섹션 테이블, 섹션으로 구분합니다.
        => 헤더 : 실행 파일이 어떤 파일이고, 어떻게 메모리에 배치되어야 하는지 설명하는 정보
        => 섹션 테이블 : 각 섹션의 파일 내 위치, 크기, 메모리 주소 등의 정보
        => 섹션 : 실제 기계어 명령어, 초기화 데이터, 읽기 전용 데이터 등이 저장된 영역
