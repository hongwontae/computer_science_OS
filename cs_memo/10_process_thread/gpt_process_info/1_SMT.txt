1. SMT (Simultaneous Multithreading) (동시 멀티스레딩)
    1-1. 가장 단순한 CPU 코어는 제어장치, ALU, 레지스터로 이루어져 있습니다.
        => 제어장치 : 명령어를 해석하고 실행을 제어
        => 레지스터 : 연산에 필요한 데이터와 결과를 보관
        => ALU : 실제 산술-논리 연산을 수행
    
    1-2. 현대 CPU 코어에는 여러 실행 유닛(Execution Unit)이 존재합니다.
        => 실행 유닛이란 CPU 코어 내부에서 명령어가 요구하는 실제 연산이나 작업을 수행하는
            하드웨어 회로를 의미합니다.
        => 대표적인 실행 유닛
            1. ALU (산술 논리 연산장치) : 정수 산술, 논리 연산 (10+20, 비트 AND)
            2. FPU (부동 소수점 연산장치) : 실수 연산 (3.14 * 2.5)
            3. Load Unit (메모리에서 데이터를 읽는 작업 처리) : 메모리의 값을 레지스터로 가져오기
            4. Store Unit (메모리에 데이터를 쓰는 작업 처리) : 레지스터 값을 메모리에 저장하기
        => CPU 코어 내부를 구체적으로 살펴보면 -> 제어장치, 레지스터들, ALU, FPU, LU, SU.. 등의 실행 유닛..
        => 현대 CPU는 조건이 맞으면 정수 덧셈과(ALU)와 실수 곱셈(FPU)를 서로 다른 실행 유닛에서 겹쳐 실행할 수 있습니다.
