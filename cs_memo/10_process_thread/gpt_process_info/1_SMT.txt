1. SMT (Simultaneous Multithreading) (동시 멀티스레딩)
    1-1. 가장 단순한 CPU 코어는 제어장치, ALU, 레지스터로 이루어져 있습니다.
        => 컴파일된 기계어 처리
        => 명령어를 가져온다. -> 명령어 해석한다. -> 필요한 데이터 준비 -> ALU 덧셈 연산 -> 결과 레지스터 저장
    
    1-2. 현대 CPU 코어에는 여러 실행 유닛이 존재합니다.
        => 실행 유닛이란 CPU 코어 내부에서 명령어가 요구하는 실제 연산이나 작업을 수행하는
            하드웨어 회로를 의미합니다.
        => ALU도 실행 유닛의 한 종류입니다.
