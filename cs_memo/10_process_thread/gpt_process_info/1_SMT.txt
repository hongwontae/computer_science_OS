1. 슈퍼 스칼라
    1-1. 가장 단순한 CPU 코어는 제어장치, ALU, 레지스터로 이루어져 있습니다.
        => 제어장치 : 명령어를 해석하고 실행을 제어
        => 레지스터 : 연산에 필요한 데이터와 결과를 보관
        => ALU : 실제 산술-논리 연산을 수행
    
    1-2. 현대 CPU 코어에는 여러 실행 유닛(Execution Unit)이 존재합니다.
        => 실행 유닛이란 CPU 코어 내부에서 명령어가 요구하는 실제 연산이나 작업을 수행하는
            하드웨어 회로를 의미합니다.
        => 대표적인 실행 유닛
            1. ALU (산술 논리 연산장치) : 정수 산술, 논리 연산 (10+20, 비트 AND)
            2. FPU (부동 소수점 연산장치) : 실수 연산 (3.14 * 2.5)
            3. Load Unit (메모리에서 데이터를 읽는 작업 처리) : 메모리의 값을 레지스터로 가져오기
            4. Store Unit (메모리에 데이터를 쓰는 작업 처리) : 레지스터 값을 메모리에 저장하기
        => CPU 코어 내부를 구체적으로 살펴보면 -> 제어장치, 레지스터들, ALU, FPU, LU, SU.. 등의 실행 유닛..
        => 현대 CPU는 조건이 맞으면 정수 덧셈과(ALU)와 실수 곱셈(FPU)를 서로 다른 실행 유닛에서 겹쳐 실행할 수 있습니다.
    
    1-3. 명령어와 스레드
        => 명령어 : CPU가 수행하는 개별 작업 / 덧셈, 데이터 읽기, 데이터 저장 등..
        => 스레드 : 자신의 실행 흐름을 가지고 여러 명령어를 차례로 수행하는 실행 단위
    
    1-4. 슈퍼 스칼라
        => 하나의 스레드의 연속적인 명령어를 병렬적으로 처리하는 기술입니다.
        => 스레드 A가 명령어를 실행 -> 제어 유닛들이 명령어를 병렬로 가져오고 해석하고 실행 유닛에 보냅니다.
        => 여러 실행 유닛이 동시에 연산을 실행합니다.


2. SMT (Simultaneous Multithreading) (동시 멀티스레딩)
    2-1. SMT는 하나의 물리 코어에서 서로 다른 여러 스레드의 명령어를 동시에 실행할 수 있도록 하는 기술입니다.

    2-2. 스레드 하나가 존재할 떄 제어 유닛과 실행 유닛이 병렬 처리
        => 만약 의존성이 존재하는 명령어라면 실행 유닛이 놀게 되는 현상이 발생할 수 있습니다.
    
    2-3. 스레드 A, B 가정 (A는 정수 계산 명령어, B는 실수 계산 명령어)
        => SMT를 지원하는 CPU 코어는 두 스레드를 Fetch, Decode, Scheduling 해서 실행 유닛으로 보냅니다.
        => A는 ALU, B는 FPU
        => 만약 B도 정수 연산을 한다면 다른 ALU를 사용할 수 있고, 실행 유닛이 하나라면 유닛을 번갈아 사용합니다.
    
    2-4. SMT를 지원하는 CPU는 스레드마다 독립적인 실행 상태를 유지할 수 있어야 합니다.
        => CPU 코어 자원을 공유하기 때문입니다.
        => 스레드는 독립적인 레지스터 상태를 유지합니다. -> 구분가능
        => 명령어 포인터, 범용 레지스터 상태(RAX, RBX), 플래그 레지스터 상태, 기타 아키텍처 상태
    
    2-5. 스레드가 공유하는 것 -> 실행 유닛, 제어 유닛, 일부 캐시와 메모리 접근 자원
    2-6. 스레드가 독립적으로 유지 하는 것 -> 2.4
