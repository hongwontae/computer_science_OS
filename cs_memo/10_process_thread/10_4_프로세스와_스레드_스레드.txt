1. 스레드
    => 프로세스를 구성하는 실행의 흐름 단위입니다.
    => 하나의 프로세스는 여러 개의 스레드를 가질 수 있습니다. / 하나의 프로세스에서 여러 개의 스레드를 동시에 실행할 수 있습니다.


2. 프로세스와 스레드
    2-1. 단일 스레드 프로세스
        => 프로세스가 하나의 실행 흐름을 가지고 한 번에 하나의 부분만 실행되는 프로세스입니다.
    
    2-2. 멀티스레드 프로세스
        => 스레드라는 개념이 도입되면서 하나의 프로세스가 한 번에 여러 일을 동시에 처리할 수 있습니다.
        => 프로세스를 구성하는 여러 명령어를 동시에 실행할 수 있습니다.
    
    2-3. 스레드의 구성 요소
        1. 스레드 ID
            => 하나의 프로세스에서 유일한 스레드 ID를 갖고 있습니다.
        2. 레지스터 값
            => 프로그램 카운터..
        3. 스택
    
    2-4. 프로세스의 스레드들은 실행에 필요한 최소한의 정보만을 유지한 채 프로세스 자원을 공유하며 실행됩니다.
        => 최근 많은 OS는 CPU에 처리할 작업을 프로세스가 아닌 스레드 단위로 전달합니다.


3. 멀티프로세스와 멀티스레드
    => 메모리 내 여러 프로세스를 동시에 실행하는 것 -> 멀티프로세스
    => 프로세스 내에서 스레드를 동시에 실행하는 것 -> 멀티스레드
    => 스레드들은 주소 공간의 코드, 데이터, 힙 영역을 공유하고 열린 파일과 같은 프로세스 자원을 공유합니다.
    => 서로 다른 프로세스들은 기본적으로 자원을 공유하지 않습니다.
    => 스레드는 프로세스의 자원을 공유하기 때문에 협력과 통신에 유리합니다. -> 효율적
    => 다만 멀티스레드 환경에서 하나의 스레드가 문제가 생기면 프로세스 전체에 문제가 생길 수 있음 -> 공유+협력


4. IPC
    => 일반적으로 프로세스끼리 자원을 공유하지 않습니다.
    => 그러나 불가능하지 않습니다. -> 프로세스 간의 자원을 공유하고 데이터를 주고받는 것을 프로세스 간 통신이라고 합니다. 
    => 프로세스들은 서로 공유하는 메모리 영역을 두어 데이터를 주고 받을 수 있습니다. -> 이를 공유 메모리라고 합니다.
