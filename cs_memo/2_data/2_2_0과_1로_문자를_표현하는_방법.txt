1. 컴퓨터는 문자를 직접 저장할 수 없습니다.
    => 컴퓨터는 0, 1만 이해하고 저장할 수 있습니다.
    => 문자 A -> 어떤 숫자 변경 -> 비트/바이트 -> 저장
    => A를 어떤 숫자로 표현할 것인가라는 문제가 발생합니다.


2. 문자 집합
    => 컴퓨터가 표현할 문자들의 목록과 각 문자를 어떤 코드 포인트를 부여하는 결정하는 것
    => A -> 0 / B -> 1 / C -> 3
    => A라는 코드 포인트(문자 코드)가 0입니다.
    => 이제 0이라는 코드 포인트를 어떤 바이트로 저장할지 결정해야 합니다. -> 인코딩

3. 인코딩
    => 문자 집합에 의해서 문자가 코드 포인트가 되었는데 이를 어떤 바이트로 치환하는 것
    => ASCII 문자 집합은 코드 포인트와 이를 통해 변경되는 바이트 값이 동일합니다. -> ASCII는 문자 집합과 인코딩 역할 붙어 있습니다.
    => A -> 65 -> 0x41

    => Unicode + Utf-8 -> Unicode는 문자 집합 / UTF-8은 인코딩 규칙
    => 가 -> 유니코드가 부여한 코드 포인트 -> U+AC00 -> UTF-8 인코딩 -> EA BO 80이 실제 메모리/파일의 바이트가 됩니다.


4. 디코딩
    => 파일에 존재하는 바이트를 코드 포인트로 변환하는 과정입니다.


5. Unicode와 UTF-8
    => Unicode는 문자에 어떤 코드 포인트를 부여할지 결정 -> 문자 집합
    => UTF-8은 그 코드 포인트를 어떤 바이트 시퀀스로 표현할지 결정 -> 인코딩
    => UTF-8, UTF-16, UTF-32 다양한 인코딩 방식이 존재하고 동일한 Unicode 포인트를 서로 다른 방식으로 바이트로 표현
    => 가의 코드 포인트 -> U+AC00
    => UTF-8 -> EA B0 80 / UTF-16 -> AC 00 / U+AC00 -> 00 00 AC 00
