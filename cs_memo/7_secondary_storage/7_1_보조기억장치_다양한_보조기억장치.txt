1. 하드디스크
    => HDD는 자기적인 방식으로 데이터를 저장하는 보조기억장치입니다. -> 자기 디스크의 일종으로 지칭하기도 합니다.
    => 자기적인 방식 : 자석의 성질을 이용하여 0과 1를 기록하는 방식 
        => 하드디스크 내부 플래터의 표면에는 자성을 띠는 물질이 얇게 발라져 있고 플래터가 회전하면서 헤드가 표면의 자기 상태를 읽거나 바꿉니다.

    1-1. 플래터
        => 하드디스크에서 실질적으로 데이터가 저장되는 곳입니다.
        => 플래터는 자기 물질로 덮여 있고 수많은 N극과 S극을 저장합니다. (N과 S는 0과 1의 역할을 수행합니다.)
    
    1-2. 스핀들
        => 플래터를 회전시키는 구성 요소를 스핀들이라고 합니다.
        => 스핀들이 플래터를 돌리는 속도는 분당 회전수를 나타내는 RPM 단위로 표현됩니다.
    
    1-3. 헤드
        => 플래터를 대상으로 데이터를 읽고 쓰는 구성 요소는 헤드입니다.
        => 헤드는 원하는 위치로 헤드를 이동시키는 디스크 암에 부착되어 있습니다.
    
    1-4. 하드 디스크는 여러 겹의 플래터로 이루어져 있고 플래터 양면을 사용합니다.
    1-5. 양면 플래터를 사용하면 위아래로 플래터당 두 개의 헤드가 사용되고 모든 헤드는 디스크 암에 부착되어 다같이 이동합니다.

    1-6. 플래터는 트랙과 섹터라는 단위로 데이터를 저장합니다.
        => 플래터를 여러 동심원으로 나누었을 떄 그 중 하나의 원을 트랙이라고 부릅니다.
        => 그 트랙을 일정한 크기로 나눈 저장 영역이 섹터입니다.
        => 하나의 섹터는 일반적으로 512 byte / 정확한 크기는 하드 디스크에 따라 차이가 존재
    
    1-7. 실린더
        => 여러 겹의 플래터 상에서 같은 트랙이 위치한 곳을 모아 연결한 논리적 단위를 의미합니다.
        => 연속된 정보는 보통 한 실린터에 기록합니다. -> 디스크 암을 움직이지 않고 바로 데이터에 접근할 수 있기 때문입니다.
    
    1-8. 하드 디스크가 저장된 데이터에 접근하는 시간은 탐색 시간, 회전 시간, 전송 시간으로 나뉩니다.
        => 탐색 시간 : 접근하려는 데이터가 저장된 트랙까지 헤드를 이동시키는 시간입니다.
        => 회전 시간 : 헤드가 있는 곳으로 플래터를 회전시키는 시간입니다. -> 섹터 찾는 것
        => 전송 시간 : 하드 디스크와 컴퓨터 간에 데이터를 전송하는 시간입니다.
    
    1-9. 다중 헤드 디스크와 고정 헤드 디스크
        => 플래터 한 면당 헤드가 하나씩 달려 있는 하드 디스크 -> 단일 헤드 디스크
        => 플래터의 헤드가 트랙별로 여러 개 달려 있는 하드 디스크 -> 다중 헤드 디스크
        => 이 떄 다중 헤드 디스크는 트랙마다 헤드가 있어 탐색 시간 0입니다.
        => 이렇게 헤드를 움직일 필요가 없는 다중 헤드 디스크를 고정 헤드 디스크 / 헤드를 데이터가 있는 곳까지 움직여야 하는 단일 헤드 디스크를 이동 헤드 디스크라고 부릅니다.


2. 플래시 메모리
    => 전기적으로 데이터를 읽고 쓸 수 있는 반도체 기반의 저장 장치입니다.
    => USB 메모리, SD 카드. SSD 모두 플래시 메모리 기반의 보조 장치입니다.
    
    => 플래시 메모리는 크게 NAND 플래시 메모리 / NOR 플래시 메모리가 있습니다.
    => 대용량 저장 장치로 많이 사용되는 플메 -> NAND 플래시 메모리

    => 플래시 메모리에서 데이터를 저장하는 가장 작은 단위는 셀(cell)입니다.
    => 셀이 모여 MB, GB, TB..
    => 하나의 셀에 몇 비트를 저장할 수 있느냐에 따라 플래시 메모리 종류가 달라집니다.
    
    2-1. SLC 타입 
        => 한 셀에 1비트를 저장할 수 있는 플래시 메모리입니다.
        => SLC 타입은 빠른 입출력 가능 (하나의 셀에 두 가지 정보만 표현하니까)
        => SLC 타입은 다른 타입보다 수명이 깁니다. -> 하드 디스크도 읽고 쓰기를 지속적으로 반복하면 수명이 짧아집니다. 
        => 1비트만 저장 -> 전압 상태를 단순하게 관리 -> 셀의 물리적 열화에 대한 판별 여부가 큼 
        => SLC 타입은 하나의 셀에 1bit 정보를 담아서 열화되더라도 0, 1를 구분하기 쉽다는 이야기입니다.
        => SLC 타입은 용량 대비 가격이 높습니다. -> 많은 양의 데이터를 저장하기 어려움
    
    2-2. MLC 타입
        => 한 셀에 2비트를 저장할 수 있는 플래시 메모리입니다. (하나의 셀에 4가지 정보 표현 가능)
        => SLC 타입보다 속도와 수명은 떨어지지만 SLC보다 많은 데이터 저장 가능 / SLC 보다 용량 대비 가격이 낮습니다.
        => 시중의 플래시 메모리 저장 장치들은 MLC | TLC입니다.
    
    2-3. TLC 타입
        => 한 셀에 3비트를 저장할 수 있는 플래시 메모리 입니다. (하나의 셀에 8가지 정보 표현 가능)
        => SLC, MLC보다 수명과 속도가 떨어집니다.
        => 다만 대용량으로 데이터 저장 가능, 용량 대비 가격 저렴합니다.
    
    2-4. 셀보다 더 큰 단위
        => 페이지 : 셀들이 모여 만들어진 단위
        => 블록 : 페이지가 모여 만들어진 단위
        => 플레인 : 블록이 모여 만들어진 단위
        => 다이 : 플레인이 모여 만들어진 단위
        
        => 플래시 메모리에서 읽기/쓰기는 페이지 단위로 이루어집니다.
        => 삭제는 블록 단위로 이루어집니다.

        => 페이지는 세 개의 상태를 가집니다.
        => Free 상태 : 어떠한 데이터도 저장하고 있지 않아 새로운 데이터를 저장할 수 있는 상태
        => Valid 상태 : 유효한 데이터를 저장하고 있는 상태
        => Invalid 상태 : 쓰레기값이라 부르는 유효하지 않은 데이터를 저장하고 있는 상태
        => 하드 디스크와 달리 덮어쓰기 불가능 -> Valid 상태인 페이지에는 새 데이터 저장 불가

        => 페이지에 데이터를 추가하고 갱신하고 싶을 떄 기존의 페이지 덮어쓰기 불가
        => 다른 페이지에 추가하고 기존의 페이지 Invalid 상태
        => 이 떄 유효한 페이지들을 모아서 다른 블록으로 보내고 기존 블록 가비지 컬렉션으로 블록 삭제
