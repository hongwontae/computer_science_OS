1. RAID의 정의
    => 데이터의 안전성 혹은 높은 성능을 위해 여러 개의 물리적 보조기억장치를 마치 하나의 논리적 보조기억장치처럼 사용하는 기술


2. RAID의 종류
    => RAID 구성 방법을 RAID 레벨이라 표현합니다.
    => RAID 레벨에는 대표적으로 RAID 0, RAID 1, RAID 2, RAID 3, RAID 4, RAID 5, RAID 6 / 파생된 RAID 10, RAID 50
    
    2-1. RAID 0
        => 여러 개의 보조기억장치에 데이터를 단순히 나누어 저장하는 구성 방식입니다.
        => 이 떄 분산되어 저장된 데이터를 스트라입 / 분산하여 저장하는 것을 스트라이핑이라고 합니다.
        => 스프라이핑을 하면 데이터를 읽고 쓰는 속도가 빨라집니다. -> 동시에 읽고 쓰기가 가능
        => 저장된 정보가 안전하지 않습니다. -> 디스크 중 하나에 문제가 생기면 모든 하드 디스크 정보를 읽는데 문제 발생
    
    2-2. RAID 1
        => 복사본을 만드는 구성 방식입니다.
        => 복사본을 만드는 구성 -> 미러링이라고도 부릅니다.
        => 복구가 매우 간단하나 사용 가능한 용량이 줄어들고 비용도 증가합니다.
    
    2-3. RAID 4
        => 오류를 검출하고 복구하기 위한 정보를 저장한 장치를 두는 구성 방식입니다.
        => 오류를 검출하고 복구하기 위한 정보 -> 패리티 비트라고 합니다.
        => RAID 4는 RAID 1보다 적은 하드 디스크로 데이터를 안전하게 보관 가능
        => 패리티 비트 : 본래 오류 검출용 정보지만 RAID에서는 오류 복구도 가능
    
    2-4. RAID 5
        => RAID 4에서 새로운 데이터 저장할 떄마다 패리티를 저장하는 디스크 데이터 씀 -> 패리티를 저장하는 장치에 병목 현상 발생
        => RAID 5에서는 패리티 정보를 분산하여 저장하는 방식으로 RAID 4의 문제인 병목 현상 해소
    
    2-5. RAID 6
        => RAID 5과 기본적인 구성은 같으나 서로 다른 두 개의 패리티를 두는 방식입니다.
        => 오류를 검출하고 복구할 수 있는 수단이 두 개나 생긴 것입니다.
        => 안전성 RAID 6 > RAID 5
        => 다만 새로운 정보 저장할 떄 함께 저장할 패리티 두 개 -> 속도가 RAID 5보다 느림
