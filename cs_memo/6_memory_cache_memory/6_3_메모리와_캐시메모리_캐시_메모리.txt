1. 저장 장치 계층 구조
    => 저장 장치는 아래의 명제를 따릅니다.
        => CPU와 가까운 저장 장치는 빠르고 멀리 있는 저장 장치는 느리다.
        => 속도가 빠른 저장 장치는 저장 용량이 작고 가격이 비싸다.
    => Register, RAM, USB 비교
        => 레지스터는 RAM보다 용량이 작지만 접근 시간이 빠르고 가격이 비쌉니다.
        => RAM은 USB 메모리보다 접근 시간은 빠르지만 가격은 더 비쌉니다.
    ** 가격이 비싸다 / 싸다 ** -> 빠른 저장 장치일수록 같은 양의 데이터를 저장하는 공간이 더 작다 -> 이걸 바싸다라고 합니다.
    => 컴퓨터가 사용하는 저장 장치들은 CPU에 얼마나 가까운가를 기준을 계층적으로 나타낼 수 있습니다. -> 저장 장치 계층 구조 (memory hierarchy)


2. 캐시 메모리
    => CPU와 메모리 사이에 위치하고 레지스터보다 용량이 크고 메모리보다 빠른 SRAM 기반의 저장 장치입니다.
    => 메모리에서 CPU가 사용할 일부 데이터를 미리 캐시 메모리로 가지고 옵니다.

    => 컴퓨터 내부에는 여러 개의 캐시 메모리가 존재합니다. 
    => 캐시 메모리들은 CPU(코어)와 가까운 순서대로 계층을 구성합니다.
    => 코어와 가장 가까운 캐시 메모리를 L1 캐시. 그 다음 L2 캐시, 그 다음 L3 캐시라고 부릅니다.
    => 일반적으로 L1, L2는 코어 내부에 / L3는 코어 외부에 위치해 있습니다.
    => CPU가 메모리 내에 데이터 필요 판단 -> L1 -> L2 -> L3 -> RAM 순입니다.
    => 멀티 코어 프로세서에서는 L1, L2를 코어의 고유한 캐시 메모리로 할당되고, L3는 여러 코어가 공유하는 형태로 사용됩니다.


3. 참조 지역성의 원리
    => 캐시 메모리는 메모리의 모든 내용을 가져다 저장할 수 없습니다.
    => 캐시 메모리는 메모리의 일부를 복사하여 저장합니다.
    => 이 떄 캐시 메모리는 CPU가 사용할 법한 대상을 예측하여 저장합니다.
    => 그리고 캐시 메모리에 예측한 데이터가 실제로 맞아 CPU에서 사용될 경우 캐시 히트라고 합니다. / 반대의 경우를 캐시 미스라고 합니다.
    => 일반적으로 컴퓨터의 캐시 적중률은 85 ~ 95
    
    => 캐시 메모리는 한 가지 원칙에 따라 메모리로부터 가져올 데이터를 결정합니다. -> 참조 지역성의 원리입니다.
        => CPU는 최근에 접근했던 메모리 공간에 다시 접근하려는 경향이 있다.
            -> C 언어에서 변수를 설정하면 자주 접근 -> CPU는 변수가 저장된 메모리 공간을 언제든 다시 참조할 수 있다.
            -> 최근에 접근했던 메모리 공간에 다시 접근하려는 경향을 시간 지역성이라고 합니다.
        => CPU는 접근한 메모리 공간 근처를 접근하려는 경향이 있다.
            -> CPU가 워드 프로세서 프로그램을 실행할 때 사용자 입력을 할 떄 입력 기능이 모여 있는 공간 근처를 집중적으로 접근합니다.
            -> 접근할 메모리 공간 근처를 접근하려는 경향을 공간 지역성이라고 합니다.
