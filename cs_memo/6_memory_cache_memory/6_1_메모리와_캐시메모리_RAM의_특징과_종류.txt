1. RAM의 특징
    => RAM에는 실행할 프로그램의 명령어와 데이터가 저장됩니다.
    => 전원을 끄면 RAM에 저장된 명령어와 데이터가 모두 사라집니다. -> 이러한 장치를 휘발성 저장 장치라고 합니다.
    => 전원이 꺼져도 내용이 유지되는 저장장치는 비휘발성 저장 장치라고 합니다. -> HDD, SDD, CD-ROM..
    => CPU는 보조기억장치에 직접 접근하지 못합니다. CPU가 실행하고 싶은 프로그램이 
        보조기억장치에 있다면 이를 RAM으로 복사하여 저장한 뒤 실행합니다.


2. RAM의 용량과 성능
    => CPU가 실행하고 싶은 프로그램이 보조기억장치에 존재 
        => RAM 용량이 적으면 보조기억장치에서 실행할 프로그램을 가져오는 일이 잦아 실행 시간이 길어집니다.
    => RAM의 용량이 크면 보조기억장치에서 많은 데이터를 가져와 미리 RAM에 저장 할 수 있습니다.
        => 보조기억장치에 접근할 횟수 자체가 줄어듬


3. RAM의 종류
    3-1. DRAM (Dynamic RAM)
        => 시간이 지나면 저장된 데이터가 점차 사라지는 RAM입니다.
        => DRAM은 데이터 소멸을 막기 위해 일정 주기로 데이터를 재활성화(다시 저장)해야 합니다.
        => 일반적 메모리 -> DRAM
        => 소비 전력이 비교적 낮고, 저렴하고, 집적도가 높기 때문에 대용량으로 설계하기가 용이
            => 집적도 : 같은 크기의 반도체 칩 안에 더 많은 메모리 셀을 넣을 수 있다는 의미입니다.
            => 대용량으로 설계하기가 용이 -> 데이터를 더 많이 저장할 수 있다.
    
    3-2. SRAM (Static RAM)
        => 시간이 지나도 저장된 데이터가 사라지지 않는 RAM입니다.
        => 주기적으로 데이터를 재활성화할 필요가 없습니다.
        => SRAM은 비교적으로 DRAM보다 속도가 더 빠릅니다.
        => SRAM은 DRAM보다 집적도가 낮고, 소비 전력도 크고 가격이 더 바싸기에 메모리로 사용되는 RAM은 DRAM입니다.
        => SRAM은 대용량으로 만들어질 필요 x, 속도가 빨라야 하는 저장장치 -> 캐시 메모리에 사용됩니다.
    
    3-3. SDRAM
        => SRAM과 관련이 없습니다.
        => 클럭 신호와 동기화된 반전된 형태의 DRAM입니다.
        => 클럭 타이밍에 맞춰 CPU와 정보를 주고받을 수 있습니다.
    
    3-4. DDR SDRAM (Double Data Rate SDRAM)
        => 대역폭을 넓혀 속도를 빠르게 만든 SDRAM입니다.
            => 대역폭 : 데이터를 주고받는 길의 너비
        => 한 클럭에 한 번씩 CUP와 데이터를 주고 받는 SDRAM / 한 클럭에 두번 씩 CPU와 데이터를 주고 받는 DDR SDRAM입니다.
        => DDR SDRAM의 전송 속도가 두 배가량 빠릅니다.
        => 한 클럭당 하나씩 데이터를 주고받을 수 있는 SDRAM을 SDR SDRAM (Single Data Rate SDRAM)이라고 합니다.
        => DDR2, DDR4 -> 대역폭이 두 배로 증가합니다. -> SDR SDRAM은 하나일 떄 DDR2 SDRAM은 4개입니다.
