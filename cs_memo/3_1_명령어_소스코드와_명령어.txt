1. 고급언어와 저급언어
    => 사람이 이해하고 작성하기 쉽도록 만들어진 언어를 고급언어라고 합니다.
    => CPU와 메모리 등 컴퓨터의 하드웨어 구조를 직접적으로 다루기 쉽게 만들어진 언어를 저급언어라고 합니다.
    
    => 저급언어는 두 가지로 볼 수 있습니다. -> 기계어, 어셈블리어
    => 기계어는 0,1 비트로 이루어진 언어입니다. 
    => 어셈블리어는 기계어를 읽기 편한 형태로 번역한 언어입니다.
    => 0101 0101 / push rbp
    => 0101 1101 -> pop rbp
    => 1100 0011 -> ret


2. 컴파일 언어와 인터프리터 언어
    => 고급언어 -> 저급언어로 변환될 떄 크게 컴파일 방식과 인터프리터 방식이 존재합니다.
    => 컴파일언어는 컴파일러에 의해서 소스 코드 전체가 저급 언어로 변환되어 실행하는 고급 언어입니다.
    => 이 떄 컴파일러가 전체 소스 코드를 보면서 오류를 발견하면 컴파일에 실패합니다. / 컴파일에 성공하면 저급 언어로 변환되고 이를 목적 코드라고 합니다.
    
    => 인터프리터언어는 인터프리터에 의해 소스 코드가 한 줄씩 실행되는 고급 언어입니다. (Python, JS)
    => 소스 코드를 한 줄씩 저급 언어로 변환하여 실행하고 이를 도와주는 도구를 인터프리터라고 합니다.
    => 인터프리터는 소스 코드 한줄 씩 실행 -> n번 째 줄 오류 -> n-1 번쨰 줄까지 실행 가능
