1. 클럭 (clock)
    1-1. 클럭은 컴퓨터 내부의 여러 동작을 동기화하기 위한 신호입니다.
    1-2. 클럭은 CPU 같은 디지털 회로가 "언제 다음 동작을 수행할지" 맞추기 위해 계속 발생시키는 전지적 박자 신호입니다.

    1-3. 클럭 신호가 빠르게 반복되면 CPU를 비롯한 컴퓨터 부품들은 빠른 박자에 맞춰 움직입니다.
    1-4. 클럭 속도는 헤르츠(Hz) 단위로 측정합니다. -> 1초에 클럭이 몇 번 반복되는지를 의미합니다.
        => 1GHz는 1,000,000,000Hz입니다.
    1-5. 클럭의 속도는 항상 일정하게 유지되는 것은 아닙니다. 고성능을 요구할 떄 순간적으로 클럭 속도를 높이고 그렇지 않을 떄 클럭 속도를 낮출 수 도 있습니다.
        => 최대 클럭 속도를 강제로 더 끌어올릴 수 있는데 이런 기법을 오버클럭킹이라고 합니다.
    1-6. 클럭 속도를 무지성으로 올리면 발열 문제가 심각해집니다. -> 한계 존재


2. 코어와 멀티코어
    => 과거 전통적인 CPU는 ALU, Register, 제어장치를 통해 명령어를 실행하는 부품으로 정의되었습니다.
    => 현재는 CPU는 발전을 거듭해서 명령어를 실행하는 부품을 여러 개 포함하는 부품을 CPU라고 합니다. -> 현재 CPU 안에는 ALU, Register, 제어장치가 하나의 세트이고 여러 세트가 존재할 수 있다는 것
    
    => 코어를 여러 개 포함하고 있는 CPU -> 멀티코어 CPU or 멀티코어 프로세서라고 부릅니다.

    => CPU의 연산속도가 항상 코어 수에 비례하여 증가하지 않습니다.
    => 업무가 균등하게 분배되지 않거나 한 두 코어만 작업을 하거나 -> 코어마다 처리할 연산이 적절히 분배되는 것이 중요합니다.


3. 스레드와 멀티스레드
    => 스레드의 사전적 의미는 실행 흐름의 단위입니다.
    => 스레드는 CPU에서 사용되는 하드웨어적 스레드 / 프로그램에서 사용되는 소프트웨어 스레드가 있습니다.

    3-1. 하드웨어적 스레드
        => 하나의 코어가 동시에 처리하는 명령어 단위를 의미합니다.
        => 2코어 4스레드 -> 햔 번에 4개의 명령어를 처리하는 CPU -> cpu 내부어 코어가 두 개이고 각각의 코어는 2개의 스레드로 2개의 명령어 처리 가능
        => 하나의 코어로 여러 명령어를 동시에 처리하는 CPU를 멀티스레드 프로세서 / 멀티스레드 CPU라고 합니다.

        => 

    
    3-2. 소프트웨어적 스레드
        => 하나의 프로그램에서 독립적으로 실행되는 단위를 의미합니다.
        => 프로그램의 여러 부분이 동시에 실행될 수 있습니다. -> 이를 멀티 스레드라고 합니다.
        => 메모리 상에서 스레드가 하나만 존재하는게 아니라 여러 개 존재하고 각각의 스레드가 실행중인 것을 의미합니다.
        => 1코어 1스레드 CPU도 소프트웨어적 스레드를 수십 개 실행할 수 있습니다.
