1. 명령어 집합 (ISA)
    => CPU가 이해할 수 있는 명령어들의 모음을 명령어 집합 | 명령어 집합 구조라고 합니다.
    => CPU마다 ISA가 다를 수 있습니다. -> 명령어로 할 수 있는 연산, 주소 지정 방식.. CPU마다 차이가 존재
    => ISA가 다르면 CPU가 이해할 수 있는 명령어가 다른 것이고 어셈블리어도 달라집니다. -> 같은 코드에 다른 어셈블리어/명령어
    => 명령어 집합은 크게 CISC, RISC로 나눌 수 있습니다.

2. CISC (Complex Instruction Set Computer)
    => CISC는 복잡한 명령어 집합을 활용하는 컴퓨터를 의미합니다.
    => 다양하고 강력한 기능의 명령어 집합을 사용하기에 명령어 형태와 크기가 다양한 가변 길이 명령어를 사용합니다.
    => 메모리에 접근하는 주소 지정 방식 다양 -> 독특한 주소 지정 방식 존재
    => 상대적으로 적은 수의 명령어로 프로그램 실행 가능 -> CISC 어셈블리어 -> RISC보다 작음
    => CISC의 가장 큰 단점 -> 명령어의 크기와 실행되기까지의 시간이 일정하지 않습니다. (명령어 복잡 + 명령어 다양한 기능 때문에)
        => 명령어 하나를 실행하는 데에 여러 클럭 주기를 필요로 합니다.
        => 이 같은 특징 때문에 명령어 파이프라인이 효율적으로 처리할 수 없습니다.
        => ex) 파이프 라인에서 명령어 n이 갑자기 실행시간이 길어지는 명령어 -> 파이프라인의 다른 명령어 n이 계속 기다림


3. RISC (Reduced Instruction Set Computer)
    => CICS보다 명령어 종류가 적고 짧고 규격화된 명령어입니다. -> RISC는 고정 길이 명령어를 사용합니다.
    => 되도록 1클럭 내외로 실행되는 명령어를 지향합니다.
    => 명령어 규격화 + 1클럭 내외로 실행 -> 명령어 파이프라이닝에 최적화되어 있습니다.
    => RISC는 메모리에 직접 접근하는 명령어를 load, store 두 개로 제한 -> 메모리 접근 단순 + 최소화 -> CISC보다 주소 지정 방식 종류가 적음
        => 이 떄문에 RISC는 레지스터를 적극적으로 활용합니다.
        => 레지스터를 이용한 연산, 범용 레지스터 개수도 많습니다.
    => 다만 사용 가능한 명령어 개수가 CISC보다 적어 많은 명령으로 프로그램 실행합니다. -> 어셈블리어가 CISC보다 깁니다.
