1. 레지스터
    => 프로그램을 실행하는데 필요한 값들을 임시로 저장하는 공간입니다.
    =>프로그램 속 명령어와 데이터는 실행 전후로 반드시 레지스터에 저장됩니다.
    

2. 8가지 레지스터
    2-1. 프로그램 카운터
        => 메모리에서 가져올 명령어의 주소를 저장합니다.
        => 프로그램 카운터를 명령어 포인터라고 부르기도 합니다.
        => 프로그램 카운터는 한 번의 사이클이 돌면 값이 증가합니다. -> 이를 통해서 순차대로 프로그램이 실행될 수 있습니다.
    
    2-2. 명령어 레지스터
        => 메모리에서 읽어들인 명령어를 저장하는 레지스터입니다.
        => 제어장치는 명령어 레지스터의 명령어를 받아들이고 해석하고 제어 신호를 내보냅니다.

    2-3. 메모리 주소 레지스터
        => 메모리의 주소를 저장하는 레지스터입니다.
        => CPU가 읽어 들이고자 하는 주소 값을 주소 버스로 보낼 떄 메모리 주소 레지스터를 거치게 됩니다.
        => 프로그램 카운터에서 바로 주소 버스를 통해 메모리에 가지 못합니다. -> 메모리 주소 레지스터를 거쳐야 합니다.
    
    3-4. 메모리 버퍼 레지스터 (메모리 데이터 레지스터)
        => 메모리와 주고받을 값(데이터, 명령어)을 저장하는 레지스터 입니다.
        => 메모리에 쓰고 싶은 값이나 메모리로부터 전달받은 값은 메모리 버퍼 레지스터를 거칩니다.
        => 데이터 버스로 주고 받을 때 메모리 버퍼 레지스터를 거쳐야 합니다.
    
    3-5. 범용 레지스터
        => 다양하고 일반적인 상황에서 자유롭게 사용할 수 있는 레지스터입니다.
        => 데이터와 주소 모두 저장 가능합니다.
    
    3-6. 플래그 레지스터
        => ALU 연산 결과 부가 정보 | CPU 상태에 대한 부가정보를 저장하는 레지스터입니다.
    
    3-7. 스택 포인터
        => RAM의 Stack 영역의 위치를 추적하는 레지스터입니다. -> Stack의 현 주소를 가지고 있습니다.
        => 스택 포인터는 스택의 꼭대기를 가리키는 레지스터입니다.
    
    3-8. 베이스 레지스터
        * 변위 주소 지정 방식
            => 오퍼랜드 필드의 값(변위)와 특정 레지스터의 값을 더하여 유효 주소를 얻어내는 주소 지정 방식입니다.
            => 변위 주소 지정 방식을 사용하는 명렁어 -> 연산코드/레지스터/오퍼랜드
            => 변위 주소 지정 방식은 상대 주소 지정 방식 or 베이스 레지스터 주소 방식등으로 나뉩니다.

        * 상대 주소 지정 방식
            => 오퍼랜드와 프로그램 카운터의 값을 더하여 유효 주소를 얻는 방식입니다.
            => 프로그램 카운터에는 명령어의 주소, 오퍼랜드는 -3 -> 읽어들이기로 한 명령어로부터 세 번째 이전을 접근 -> -3 명령어 실행

        * 베이스 레지스터 주소 지정 방식
            => 오퍼랜드와 베이스 레지스터 값을 더하여 유효 주소를 얻는 방식입니다.
            => 베이스 레지스터는 기준 주소 / 오퍼랜드는 기준 주소로부터 떨어진 거리의 역할을 합니다.
            => 베이스 레지스터 속 기준 주소로부터 얼마나 떨어져 있는 주소에 접근할 것인지를 연산하여 유효 주소를 얻어내는 방식입니다.
            => 베이스 레지스터 200 / 오퍼랜드 40 -> 기준 주소 200으로부터 40 떨어진 240에 접근하라
