1. C언어의 .c 파일에서 실제 실행 파일이 되는 과정은 크게 4가지입니다.

2. 전처리
    => 전처리기가 .c 파일의 #inclde, #define 같은 전처리 지시문을 처리합니다.
    => 컴파일 전에 #include 선언을 가져와서 포함시킵니다. -> 컴파일러가 오류를 내지 않게 하기 위해서
    => .h 파일은 함수/자료형의 선언을 제공하는 파일 / .c는 함수 등의 구현을 제공하는 파일
    => #include는 헤더의 내용을 현재 소스 코드에 포함시키는 전처리 작업입니다.

    #include <stdio.h>

    int main(void)
    {
        printf("Hello\n");
    }

    ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓

    int printf(const char *format, ...);
    int main(void)
    {
        printf("Hello\n");
    }


3. 컴파일
    => 전처리된 C 코드를 어셈블리 코드로 변환합니다.


4. 어셈블
    => 어셈블리 코드를 기계어로 변환합니다.
    => 어셈블 후 목적 파일이 됩니다.


5. 링크
    => 링커가 여러 목적 파일과 라이브러리를 연결해서 하나의 프로그램으로 만듭니다. 



6. 그림
    ┌──────────────┐
    │    hello.c   │
    │   C 소스코드 │
    └──────┬───────┘
        │
        ▼
    ┌──────────────┐
    │   전처리기    │
    │ #include 등  │
    └──────┬───────┘
        │
        ▼
    ┌──────────────┐
    │   컴파일러    │
    │ C → Assembly │
    └──────┬───────┘
        │
        ▼
    ┌──────────────┐
    │   어셈블러    │
    │ Assembly →   │
    │ Machine Code │
    └──────┬───────┘
        │
        ▼
    ┌──────────────┐
    │    hello.o   │
    │ 목적 파일     │
    └──────┬───────┘
        │
        │ + 라이브러리
        ▼
    ┌──────────────┐
    │    링커       │
    └──────┬───────┘
        │
        ▼
    ┌──────────────┐
    │   hello.exe  │
    │  실행 파일    │
    └──────────────┘
