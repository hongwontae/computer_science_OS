1. CPU 내부의 레지스터가 존재하고 32bit -> 64bit로 진화했습니다.

2. 64bit 레지스터는 32bit 레지스터보다 더 넓은 범위의 값을 표현할 수 있습니다.

3. 32bit vs 64bit 차이
    3-1. 데이터 처리
        => 64bit 레지스터를 이용하면 64bit의 데이터를 담아 처리할 수 있습니다.
        => 32bit보다 더 큰 양의 데이터 처리 가능
    3-2. 메모리 주소 범위
        => 64bit 메모리 주소를 담아 처리할 수 있습니다.
        => 더 폭 넓은 메모리 주소 지원
    3-3. 메모리 활용
        => 더 넓은 주소 공간을 이용할 수 있어 대용량 RAM과 더 큰 가상 주소 공간 활용에 유리합니다.


4. 실행환경에 따라 32bit 환경을 x86라고 합니다.
5. 실행환경에 따라 64bit 환경을 x64라고 합니다.

6. c언어에서 32bit 환경에서는 sizeof(void *) -> 32 / 64bit 환경에서는 sizeof(void *) -> 64
