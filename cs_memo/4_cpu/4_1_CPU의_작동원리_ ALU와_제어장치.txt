1. ALU
    => ALU는 레지스터를 통해 피연산자를 받아들이고 제어장치의 제어신호로 연산자를 받아들여서 연산을 수행합니다.
    => 제어신호는 수행할 연산을 알려주는 것 -> 즉, 연산자
    => ALU가 내보내는 정보는 결과값과 플래그입니다.
    => 결과값은 메모리에 바로 저장되지 않고 일시적으로 레지스터에 저장됩니다. -> 계산마다 메모리 접근 -> 속도 느려짐
    => 플래그는 결과값에 대한 추가정보입니다. 플래그는 플래그 레지스터에 저장됩니다.
    => 플래그 종류 (부호 플래그(양수/음수), 제로 플래그(연산결과 0 여부), 캐리 플래그(연산결과 올림수/빌림수), 오버플로우 플래그, ..)

2. 제어장치
    => 제어장치는 명령어를 해석하고 제어신호를 내보내는 장치입니다.
    => 제어신호는 컴퓨터 부품들을 관리하고 작동시키기 위한 일종의 전기 신호입니다.

    * 클럭(Clock) -> 컴퓨터의 모든 부품들이 일사불란하게 움직일 수 있게 하는 시간 단위입니다.
    => 제어장치는 클럭이라는 시간 단위를 받아들입니다.

    => 제어장치는 명령어 레지스터로부터 해석할 명령어를 받아들이고 해석하고 제어 신호를 발생시킵니다.

    => 제어장치는 플래그 레지스터 속 플래그 값을 받아들이고 이를 참고하여 제어 신호를 발생시킵니다.

    => 제어장치의 제어 신호는 cpu 내부 전달 or cpu 외부 전달이 존재합니다.
    => 외부로 전달할 떄는 제어 버스로 제어 신호를 전달합니다.

    => 제어 신호는 제어장치만 발생시킬 수 있는게 아닙니다. 다른 외부 장치도 제어 신호를 발생시킬 수 있고 이 떄 제어 버스를 통해 전달됩니다.
