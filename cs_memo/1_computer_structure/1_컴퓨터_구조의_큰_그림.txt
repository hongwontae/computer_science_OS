1. 컴퓨터 구조는 크게 두 가지입니다.
    => 컴퓨터가 이해하는 정보 / 컴퓨터의 네 가지 핵심 부품

2. 컴퓨터가 이해하는 정보 (모든 정보는 0,1로 이루어져 있습니다. 컴퓨터는 0,1 표현된 정보만 이해합니다.)
    2-1. 데이터
        => 컴퓨터가 이해하는 정적인 정보를 데이터라고 합니다.

    2-2. 명령어
        => 컴퓨터를 작동시키는 정보를 명령어라고 합니다.
    

3. 컴퓨터의 네 가지 핵심 부품
    3-1. CPU
        => ALU(산술논리연산장치), 제어장치, 레지스터를 통해서 메모리의 명령어를 읽어들이고 해석하고 실행합니다.
        => ALU는 계산기, 레지스터는 CPU 내 임시 저장 장치
        => 제어 장치는 제어 신호를 내보냅니다. -> 제어 신호는 컴퓨터 부품을 관리하거나 작동시키기 위한 전기 신호입니다.
        => 제어 신호 ex) cpu가 메모리에 저장된 값 읽고 싶을 떄 -> 메모리 읽기 제어 신호 / cpu ram 저장하고 싶을 때 -> 메모리 쓰기 제어신호
        => 제어 장치는 명령어를 해석합니다.

    3-2. 주 기억 장치 (RAM -> Ramdom Access Memory)
        => 메모리는 현재 실행되는 프로그램의 명령어와 데이터를 저장하는 부품입니다.
        => 메모리의 저장된 값은 빠르고 효율적으로 접근하기 위해 주소가 존재합니다.
        => RAM은 전원이 꺼지면 저장된 내용을 잃습니다.

    3-3. 보조 기억 장치 (SSD, HDD)
        => 전원이 꺼져도 저장된 내용을 잃지 않는 메모리를 보조 기억 장치라고 합니다.

    3-4. 입출력장치
        => 컴퓨터 외부에 연결되어 컴퓨터 내부와 정보를 교환하는 장치를 의미합니다.

    ** 메인보드
        => 컴퓨터의 각 부품을 서로 연결하고 통신하게 만드는 가장 큰 회로 기판입니다.
        => 메인보드에는 각 부품이 서로 데이터를 주고 받을 수 있도록 전기적인 통로가 있습니다.
        => 이 전기적인 통로를 버스라고 합니다.
        => 버스 중 핵심적인 버스를 시스템 버스라고 합니다. -> 컴퓨터 네 가지 핵심 부품이 서로 정보를 주고 받는 통로입니다.
        => 시스템 버스의 내부 구성은 주소 버스(주소 주고 받음), 데이터 버스(명령어와 데이터를 주고받음), 제어 버스(제어 신호 주고받음)로 구성되어 있습니다.
    
    ** 시스템 버스 동작
        => CPU가 RAM에서 데이터를 읽을 때
        => CPU
            │
            ├─ 주소 버스 ─────→ RAM
            │                  "이 주소의 데이터를 줘"
            │   
            ├─ 제어 버스 ─────→ RAM
            │                  "읽기(Read)!"
            │
            │
            └← 데이터 버스 ──── RAM
                                "여기 데이터!"
        => RAM 입장에서 주소 버스를 보고 n 주소의 데이터 요청을 알고, 제어 버스 신호를 보고 읽기 요청을 알아냅니다.
        => RAM 내부의 회로가 n 주소에 해당하는 메모리 셀의 값을 찾아서 데이터 버스에 올리고 cpu에게 데이터 버스로 전달받은 값을 가져갑니다.
        => ** cpu 제어 신호 발생 -> ram 내부 회로가 자체적인 동작 -> cpu data get
